
# POS 扫码自动化工具

自动执行 POS 系统扫码操作的 Python 脚本，支持条码输入、会员扫码、参数配置与记录管理。
目前仅支持金叶通云POS，与其他POS的相符性未知。

## 功能特点

-  **全自动扫码** – 按设定的时间间隔自动输入条码并确认
-  **双模式条码** – 支持两种条码来源（方法1 / 方法2），可配置概率
-  **会员扫码** – 自动输入会员号，支持失败重试和弹窗处理
-  **均衡算法** – 每月确保每个会员至少被扫码一次，优先选择当月未扫会员
-  **全局热键** – `Alt+X` 立即执行一次扫码
-  **记录管理** – 查看历史扫码记录及当月未扫会员列表
-  **参数调节** – 内置 GUI 面板，可实时修改扫码间隔、模式概率、VIP 概率

## 环境要求

- Windows 操作系统（依赖 `pyautogui`、`ctypes` 等 Windows API）
- Python 3.8 或更高版本

## 安装步骤   注：有exe版本可直接使用，直接运行exe文件即可

1. **下载仓库**

2. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

   依赖列表（`requirements.txt`）：
   ```
   pyautogui
   opencv-python
   numpy
   pynput
   pygame
   ```

3. **准备资源文件（全部已自带，可自行修改）**

  -  `assets/pos_icons/` 文件夹，放入识图所需的 PNG 图标：
      - `member.png` – 会员图标
      - `confirm.png` – 确定按钮
      - `clear.png` – 清除按钮
      - `vip_fail.png` – 获取会员信息失败提示
      - `confirm_payment.png` – 确认收款按钮
      - `cash.png` – 现金按钮
> 注：可使用截图工具从 POS 界面截取对应按钮区域，保存为 PNG，确保背景干净、尺寸适中。
   -  `assets/gui/` 文件夹，程序的UI图片，略
   - 根目录下准备 JSON 数据文件：
     - `不能扫在线的条码.json` – 方法1 条码列表（字符串数组）
     - `可以扫在线的条码.json` – 方法2 条码列表（字符串数组）
     - `vip列表.json` – 会员编号列表（整数数组）

   > 示例 `vip列表.json`：
   > ```json
   > [01, 02, 03]
   > ```

   

## 使用方法

### 启动程序
双击打开pos.py

程序会自动请求**管理员权限**（用于全局热键及模拟输入）。

### 扫码流程

1. 程序自动按间隔触发扫码
2. 模拟 `Alt+Z` 唤醒 POS 窗口（可根据需要修改按键）
3. 检测界面图标（会员 / 确认收款+现金），确保 POS 已就绪
4. 根据配置的概率选择条码来源（方法1 / 方法2）
5. 输入条码并回车
6. 若触发 VIP 扫码：
   - 点击“会员”图标
   - 输入会员号（自动补齐 `000` 前缀）
   - 点击“确定”
   - 处理可能出现的“获取会员信息失败”弹窗
7. 按 `Shift+=` 组合键（根据实际 POS 快捷键调整）并最终确认

## 配置说明

| 配置文件 | 作用 |
|----------|------|
| `不能扫在线的条码.json` | 方法1 条码库 |
| `可以扫在线的条码.json` | 方法2 条码库 |
| `vip列表.json` | 所有会员编号 |
| `会员扫码记录.json` | 自动生成，记录每次成功扫入的会员及时间 |
| `assets/pos_icons/*.png` | 图像识别模板 |

> 图像识别相似度阈值默认为 `0.95`，可在代码中 `_IMG_CONF` 变量调整。
